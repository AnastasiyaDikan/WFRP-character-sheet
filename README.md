# WFRP 4e — веб-лист персонажа

Первый локальный прототип листа персонажа по Warhammer Fantasy Roleplay 4 редакции.

## Запуск

1. Откройте папку проекта в VS Code.
2. В терминале выполните `npm install`.
3. Запустите `npm run dev`.
4. Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Что уже работает

- классы, связанные карьеры, четыре карьерных уровня, путь и статус;
- карьерная подсветка характеристик, умений и талантов без удаления ранее открытых навыков;
- расчёт характеристик, умений, опыта, движения и ран, включая талант «Стойкий»;
- локальные справочники умений, талантов и заклинаний — сайт-источник для работы листа не нужен;
- фильтр заклинаний по школам, полные параметры и сворачиваемые эффекты;
- автоматическая подстановка бонусов характеристик прямо в ячейку длительности (`рСВ минут` → `7 минут` при СВ 78), при этом исходная формула сохраняется в JSON;
- выбор вида персонажа и автоматически меняющаяся карта попаданий: человек, дварф, полурослик, высший/лесной эльф, гном и огр;
- максимум талантов по характеристикам и счётчик вида `1/6`, полные сворачиваемые описания;
- броски характеристик и умений на d100, а также палитра d4–d100;
- необязательная отправка бросков в Discord через вебхук;
- автосохранение в браузере, импорт и экспорт JSON, адаптивный и печатный режимы.

## Discord

1. В Discord откройте настройки нужного канала → «Интеграции» → «Вебхуки».
2. Создайте вебхук и скопируйте его URL.
3. В листе откройте круглую кнопку кубов → `Discord`, вставьте URL, нажмите «Проверить», включите отправку и сохраните.

URL хранится только в `localStorage` текущего браузера. Он не попадает в JSON персонажа, исходники или Git. Вебхук является секретом: не публикуйте его и при утечке сразу удалите в настройках Discord.

## Публикация через GitHub Pages

Проект уже содержит готовый workflow `.github/workflows/deploy-pages.yml`.

1. Создайте пустой репозиторий GitHub и загрузите в него содержимое этой папки:

   ```bash
   git init
   git add .
   git commit -m "WFRP character sheet"
   git branch -M main
   git remote add origin https://github.com/ИМЯ/РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

2. В репозитории откройте `Settings → Pages` и в `Source` выберите `GitHub Actions`.
3. Дождитесь зелёного выполнения workflow `Deploy WFRP sheet to GitHub Pages` во вкладке `Actions`.
4. Адрес появится в `Settings → Pages`; обычно это `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

Для другого статического хостинга выполните `npm run build` и загрузите содержимое папки `dist`. Серверная часть не требуется.

Версия прототипа: `0.9.1`.
